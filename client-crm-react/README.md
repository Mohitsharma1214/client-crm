# 🚀 Client CRM (React + TypeScript)

A standalone, production-ready React 18 + TypeScript + Vite CRM engineered with an editorial Anthropic warm-ivory design system, tactile drag-and-drop Kanban pipeline, 1-Click WhatsApp outreach dispatcher, smart Google Maps contact card parser, and niche conversion funnels.

---

## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open **`http://localhost:3000`** in your browser.

### 3. Production Build
```bash
npm run build
npm run preview
```

## 📦 What's Included

- **32 Verified High-Ticket Prospects Preloaded**: Real clinics, cosmetic aesthetic centers, and luxury architecture firms in Gurugram / Delhi NCR with phone numbers, decision makers, and audited pitch angles.
- **⚡ 1-Click WhatsApp Blast Dispatcher**: Batch sequence that launches pre-filled WhatsApp deep-links with custom pitch angles and progress tracking.
- **📅 Smart Follow-Up Workspace**: Tracks Overdue, Due Today, and Upcoming (1-2d) touches with tailored 2nd-touch WhatsApp templates.
- **📊 Niche Conversion & Performance Analytics**: Calculates conversion rates and pipeline value across Dentistry, Aesthetic Clinics, Interior Design, Real Estate, and Salons.
- **📍 Smart Google Maps / Visiting Card Auto-Fill**: Automatically parses phone numbers, websites, doctor names, and categorizes pain points from pasted text.
- **📱 100% Mobile & Tablet Responsive**: Custom-built card views for mobile screens with zero text overflow, responsive filter wraps, and touch-optimized buttons.
- **🌗 Dark / Light Mode Switcher**: Anthropic editorial warm ivory theme with smooth toggle.
- **💾 LocalStorage Reactivity**: Automatically persists all client stage movements, notes, and added leads.
